# Кандидатогенерация для поиска услуг Авито (Recall@50)

Для каждого поискового запроса решение отбирает из корпуса в 189 тысяч объявлений 50 кандидатов так, чтобы среди
них оказалось объявление, которое пользователь выбрал. Подход:

1. Поиск по словам BM25 (со стеммингом) в окрестности локации поиска с мягкими фильтрами "Вид услуги" и категория. (Мягкий фильтр = если локация объявления и пользователя не совпадает, то мы не удаляем объявление, а просто не прибавляем к его score большую константу)
2. Пул ~450 кандидатов из пяти источников: BM25, дообученные эмбеддинги `sergeyzh/rubert-mini-frida`,
   классификатор "запрос → подкатегория", "память" train, BM25 без локации.
3. Ранкер CatBoost на ~45 признаках пары "запрос — кандидат" выбирает из пула 50 лучших.

| Шаг | Recall@50, валидация | Recall@50, лидерборд |
|---|---|---|
| BM25 + окрестность локации + фильтры (бейзлайн) | 0.822 | 0.770 |
| Пул из 5 источников + ранкер CatBoost | 0.924 | 0.881 |

## Файлы

```
solution.ipynb          ноутбук: исследование и решение по шагам, создаёт answer.csv
answer.csv              ответ, отправленный на Stepik (Recall@50 = 0.8812)
requirements.txt        версии библиотек
dataset/                сюда положить train.parquet, benchmark_queries.parquet, benchmark_items.parquet
cache/                  дообученная нейросеть и эмбеддинги (архив cache.zip в разделе Releases)
```

## Как запустить

1. `pip install -r requirements.txt`
2. Положить три parquet-файла в `dataset/`.
3. Для точного воспроизведения ответа скачать `cache.zip` со страницы
   [Releases](https://github.com/Igorekkek/Avito_test/releases) и распаковать в папку проекта — появится папка `cache/`
   с дообученной нейросетью (`rubert-mini-frida-ft/`) и эмбеддингами (`emb_finetuned.npz`, `emb_pretrained.npz`).
4. Открыть `solution.ipynb` и выполнить все ячейки сверху вниз. Результат — `answer.csv` рядом с ноутбуком.

С папкой `cache/` нейросеть не обучается заново, интернет не нужен, и ноутбук воспроизводит отправленный `answer.csv`. 
Без неё нейросеть скачивается с HuggingFace и дообучается заново. Нейросеть небольшая, 32m, на CPU обучалась минут 40-50; обучение на другом железе даёт немного другие веса,
поэтому ответ может незначительно отличаться при том же качестве.

Видеокарта используется автоматически (только для нейросети). BM25, пулы кандидатов и CatBoost работают на CPU;
CatBoost намеренно обучается на CPU с фиксированным числом потоков, чтобы результат воспроизводился.

Время выполнения и требования к памяти — в начале ноутбука, в разделе "Как запустить".

## Важное уточнение

* Лучшая отправка на Stepik (Recall@50 = 0.8860) - экспериментальный вариант обучения ранкера, который не вошёл в итоговое решение.
* Последнее отправленное решение это `solution.ipynb` с ответом `answer.csv` воспроизводит побайтово отправку на Stepik с Recall@50 = 0.8812. 

## Использованные open-source компоненты

pandas, numpy, scipy, scikit-learn (TF-IDF, логистическая регрессия), CatBoost, snowballstemmer, pymorphy3,
PyTorch, sentence-transformers, открытая модель эмбеддингов
[sergeyzh/rubert-mini-frida](https://huggingface.co/sergeyzh/rubert-mini-frida). BM25 реализован вручную на scipy.
Внешние API не используются.
